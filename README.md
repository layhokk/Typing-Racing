# Typing Racer

A free typing race game that runs in the browser (computer or phone).

- Beginner, Intermediate and Advanced levels with English words and full sentences
- Race computer-controlled cars, or race friends in a live room
- Wrong keys are blocked: you can only move on after typing the right letter
- Speed (WPM), timer, accuracy, score and a top-3 leaderboard
- Performance Analytics: speed trend, accuracy, speed vs. accuracy, finishing positions, with written interpretation

Created by Lay Hok Houn, Business Analyst | Data & Insights.

## Run it
Open `index.html` in any browser. To put it online, enable GitHub Pages (Settings > Pages > Deploy from branch > main).

Note: the "Race friends" live rooms need the page to be hosted on Claude, so they will not work from GitHub Pages.
